# Shared Budget Manager

A local-first personal and shared budgeting app for Gowri and Nathaniel.

## Local Development

```bash
npm install
npm run dev
```

The Vite dev server opens the React app with local IndexedDB persistence.

## Quality Gates

```bash
npm test
npm run typecheck
npm run lint
npm run test:e2e
npm run build
```

## Production Build

```bash
npm run build
npm run preview
```

The production output is written to `dist/`.

## PWA Behavior

The app is installable-capable as a PWA. It includes a web app manifest, app icons, iOS mobile metadata, and a service worker generated by `vite-plugin-pwa`.

The service worker uses an app-shell/static asset caching strategy with automatic updates. Financial records are not cached by the service worker as an alternate data source; they remain in IndexedDB through the existing repository layer.

After the app has loaded once, the application shell should be available offline, and existing local IndexedDB data should remain available in that same browser/device.

## Current Persistence Model

Financial data is currently stored locally in IndexedDB and therefore does not yet synchronize between devices.

Opening the application on two devices currently creates two separate local datasets. Gowri's phone, Nathaniel's phone, and a laptop browser will each have their own local data until the future Supabase synchronization phase is implemented.

## Install On Phone

On iPhone:

1. Open the deployed app in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch the app from the home screen.

On Android:

1. Open the deployed app in Chrome.
2. Use Install app or Add to Home screen from the browser menu.
3. Launch the app from the home screen.

## Vercel Deployment

This is a static Vite SPA. `vercel.json` rewrites all routes to `index.html` so React Router deep links such as `/dashboard`, `/transactions`, and `/budgets` reload without a server 404.

Recommended Vercel settings:

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

## GitHub Deployment Path

If no remote exists yet:

```bash
git remote add origin <your-github-repo-url>
git branch -M main
git push -u origin main
```

Then connect that GitHub repository to Vercel.

## Future Sync Architecture

The planned architecture is:

```text
PWA/web frontend
+ local IndexedDB
+ Supabase auth/shared backend/sync
```

Supabase, authentication, shared households, conflict resolution, and cross-device synchronization are intentionally not implemented yet.
